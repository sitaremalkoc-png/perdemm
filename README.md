# Perde AI Studio 0.2 — PWA + Hugging Face ZeroGPU

Perde AI Studio is a responsive Progressive Web App for mobile, tablet, and desktop. It accepts a room photo and a fabric reference photo, then sends both to Qwen Image Edit 2509 through a Hugging Face Gradio Space. The PWA includes password login, room/fabric previews, curtain and pleat choices, a privacy consent gate, progress polling, and image download.

## Important architecture and privacy notes

- The browser never receives the Hugging Face token. `HF_TOKEN` is read only by `server.js` from the hosting provider's secret environment variables.
- The app server does not persist uploaded photos to disk; uploads are held in memory for the request. The selected Hugging Face Space receives the images for inference. Its own service processing/retention terms apply.
- The current default backend is the official public Space `Qwen/Qwen-Image-Edit-2509`, currently shown as running on ZeroGPU. Its source shows a multi-image Gallery input and an `infer` function. The PWA sets `rewrite_prompt=false`, avoiding that Space's optional external DashScope prompt-rewrite path.
- Hugging Face currently documents 5 minutes of free-account ZeroGPU quota per 24-hour cycle, resetting 24 hours after the first GPU use. A single image generation can consume a substantial part of that quota; queue time and actual GPU time vary. We set 20 inference steps as a slower/cheaper starting point, not a guaranteed number of images.
- A free personal Hugging Face account can host up to two of its own ZeroGPU Spaces only when the account is in good standing, has a verified email, and is older than 30 days. The user's new account can use existing public ZeroGPU Spaces now, but cannot host its own free ZeroGPU Space until eligible. The 30-day condition applies to hosting your own Space, not to using an existing public ZeroGPU Space.
- To make the model endpoint private later, upload `hf-space/` to a new private Gradio Space after eligibility and change the Render environment variables to `HF_SPACE_ID=sitaremalkoc/perde-ai-studio-model`, `HF_API_NAME=/generate`, `HF_API_MODE=perde-custom`. The optional private Space template is included but has not been deployed or GPU-tested yet.
- No OpenAI API key is required for this Hugging Face route. OpenAI image API usage would be a separate paid route and is intentionally not enabled.

## Local setup

1. Install Node.js 20 or newer.
2. Copy `.env.example` to `.env`.
3. Set `APP_PASSWORD` to a unique long password.
4. Set `SESSION_SECRET` to a random secret of at least 32 characters.
5. Create a Hugging Face personal access token with Read permission and set `HF_TOKEN` in `.env` (never commit `.env`).
6. Run:

   ```bash
   npm install
   npm start
   ```

7. Open `http://localhost:3000`.

For a UI/server smoke test without contacting an AI service, set `AI_MOCK=true` in `.env`. This produces a labelled mock illustration only; it is not a real curtain-generation result. Never set `AI_MOCK=true` in production.

## Hugging Face token

Create a token at <https://huggingface.co/settings/tokens>. Use the least permissions that still allow access to the selected Space (Read). Keep it in the hosting provider's secret environment settings. Never paste it into ChatGPT, the PWA, GitHub source, or a screenshot.

## Deploy to Render (free web service)

1. Create a private GitHub repository and upload the contents of this folder (not the outer parent folder).
2. In Render, choose **New → Blueprint** and connect that repository. Render reads `render.yaml`.
3. In the new service's Environment page, set:
   - `APP_PASSWORD`: a strong password known only to the owner.
   - `HF_TOKEN`: the Hugging Face Read token.
4. Confirm the other variables from `render.yaml`, then deploy.
5. Wait for `/healthz` to return `{ "ok": true }`, then open the Render URL and sign in.

Render's free service may sleep when idle and take time to wake. The PWA shell can be installed on mobile/desktop over HTTPS; AI generation still requires an internet connection. Render free web services sleep after 15 minutes without incoming traffic and can take about a minute to wake.

## Deployment checklist

- [ ] `APP_PASSWORD` configured in Render (not in source code)
- [ ] `SESSION_SECRET` generated by Render
- [ ] `HF_TOKEN` stored as a secret in Render
- [ ] Render deployment successful and `/healthz` returns 200
- [ ] Login tested on phone and desktop
- [ ] Hugging Face ZeroGPU call tested with the user's own room and fabric samples after explicit consent
- [ ] PWA installation tested on the target browser

## Known limitations

- The official public Space is operated by its owner. Although the PWA is password-protected, the two uploaded images are sent to that external Space. Use the private custom Space later if strict endpoint privacy is required.
- AI can approximate the fabric's color, weave, and pattern; it is not a color-calibrated product proof or measurement tool.
- Daily free GPU quota and queue availability are controlled by Hugging Face, not this app.
- No app has been deployed by this repository alone. Hosting requires the user's GitHub/Render account and explicit setup of the secrets.
